# Another error: what to send to support

## Symptom
The panel shows an error this guide has no own article for. Under the error box there is an **incident code** such
as `K7F3Q2` with the time.

## Cause
Many things outside the panel can fail: a download, a website's own code, the provider's network. The panel writes
every error with its incident code to its log, so support can find exactly what happened.

## How to check
1. Read the error once more: it often names what to change (a field, a name, a size).
2. Search this guide for a word of the error.
3. Try once more after a minute: a short network problem goes away by itself.

## Fix
When the error stays, send support:
- the **incident code** and the time shown next to it (with the time zone),
- the website's domain and the page you were on,
- what you pressed or typed (never a password, key or code),
- a screenshot, if you can.

## Still stuck?
Server admins can find the incident code in the panel's log on the server. Hosting accounts send the information above
to the server's admin or to their provider's support.
