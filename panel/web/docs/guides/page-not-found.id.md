# "Tidak ditemukan" untuk halaman yang ada

## Gejala
Halaman atau website yang Anda harapkan menjawab "Tidak ditemukan" (404).

## Penyebab
- Alamatnya salah ketik, atau website sudah dipindahkan ke tempat sampah.
- Akun Anda tidak boleh membuka halaman itu. Panel sengaja menjawab "Tidak ditemukan", bukan "dilarang", supaya tidak
  ada yang bisa tahu website apa saja yang ada di server. Halaman server (pengaturan, disk server, log aktivitas,
  pembaruan) hanya untuk admin server, dan akun hosting hanya melihat websitenya sendiri.

## Cara cek
1. Buka **Website** dari menu: daftarnya memuat setiap website yang boleh Anda buka.
2. Buka website dari daftar itu, bukan dari bookmark lama.

## Solusi
- Website tidak ada di daftar Anda: tanyakan ke admin server apakah website itu dihapus atau diberikan ke akun lain.
- Anda butuh halaman server: minta admin server mengerjakannya untuk Anda.

## Masih belum bisa?
Kirim ke support kode artikel **NP-TS-006**, alamat yang Anda buka, dan jamnya (dengan zona waktunya).
