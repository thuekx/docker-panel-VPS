## How it works

- **All WordPress work runs WP-CLI in the site's own `cli` container** (uid 33, its own database, `--rm`).
  One `docker compose run` carries a batch of commands; each command's stdout, stderr and exit code are
  separated by a random marker. Arguments are single-quoted for `sh -c`; nothing from a request reaches a shell
  line: plugin/theme names must match `^[A-Za-z0-9][A-Za-z0-9._-]*$` (never a flag), install slugs
  `^[a-z0-9][a-z0-9-]*$`, settings are a fixed list.
- **Outbound internet for the cli container** (new `out` network) for updates, check-update and checksums.
  The agent re-renders a site's compose file before WordPress Tools use it; running containers are untouched.
- **One-click login**: the agent writes the must-use plugin `wp-content/mu-plugins/nostek-panel.php`, creates
  a 32-byte random token, stores `sha256(token)`, the admin login and an expiry (60 s) in a WordPress option
  through WP-CLI (the hash travels as an environment value, never the token). The panel shows a page that
  follows `https://<site>/?nostek_login=<token>` (a link, so CSP `form-action 'self'` stays). The plugin checks
  with `hash_equals`, spends the option, sets the auth cookie and redirects to wp-admin.
- **Maintenance mode** is an option read by the same plugin on `template_redirect`: visitors get a 503 page
  with `Retry-After`; logged-in admins, wp-admin and wp-login are not affected. (WP-CLI's own maintenance mode
  ends by itself after 10 minutes, so it is not used.)
- **Debugging** sets `WP_DEBUG`, `WP_DEBUG_LOG = '/dev/stderr'`, `WP_DEBUG_DISPLAY = false`: errors land in the
  container log shown on the website page, never in a public `debug.log`.
- **System cron** sets `DISABLE_WP_CRON` and `site.json` `system_cron`; the agent runs
  `php wp-cron.php` as uid 33 in the site's web (Apache) or php (Nginx) container every 5 minutes.
- **HTTPS status**: the agent opens TLS to the local edge with the site's name and checks it like a browser.
- **Locking**: changes (updates, installs, settings, console) take the agent's change lock (409 while busy);
  reading the overview does not.
- **Audit**: action, site and plugin/theme names; for the console only the command name and length.
