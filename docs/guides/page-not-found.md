# "Not found" for a page that exists

## Symptom
A page or a website you expect answers "Not found" (404).

## Cause
- The address has a typo, or the website was moved to the trash.
- Your account may not open that page. The panel answers "Not found" instead of "forbidden" on purpose, so nobody
  can find out which websites exist on the server. Server pages (settings, server disk, activity log, updates) are
  for the server's admins only, and a hosting account sees only its own websites.

## How to check
1. Open **Websites** from the menu: the list holds every website you may open.
2. Open the website from that list instead of an old bookmark.

## Fix
- The website is missing from your list: ask the server's admin whether it was deleted or given to another account.
- You need a server page: ask the server's admin to do it for you.
